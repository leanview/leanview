## Español

### Cómo comunicar una vulnerabilidad

- Para un problema que se pueda describir en público: abre una incidencia en <https://github.com/leanview/leanview/issues>.
- Para un problema que no debe verse hasta que esté corregido: usa el aviso privado de seguridad de GitHub (pestaña **Security** del repositorio, **Report a vulnerability**): <https://github.com/leanview/leanview/security/advisories/new>.

Incluye la versión de LeanView (Ajustes > Acerca de), el aparato y los pasos para reproducirlo. No incluyas contraseñas, códigos de inicio de sesión ni datos de tu cuenta.

### Qué versiones reciben correcciones

Solo la última versión publicada en <https://github.com/leanview/leanview/releases/latest>.

### Cómo comprobar lo que descargas

Los APK están firmados con un certificado propio de LeanView (`CN=Leanview`). Su huella SHA-256 está en el [README](README.md#comprobar-que-la-descarga-es-auténtica). Instala LeanView solo desde esa página de versiones.

## English

### How to report a vulnerability

- For a problem that can be described in public: open an issue at <https://github.com/leanview/leanview/issues>.
- For a problem that must not be visible until it is fixed: use GitHub's private security advisory (the repository's **Security** tab, **Report a vulnerability**): <https://github.com/leanview/leanview/security/advisories/new>.

Include the LeanView version (Settings > About), the device and the steps to reproduce. Do not include passwords, sign-in codes or account data.

### Which versions get fixes

Only the latest release at <https://github.com/leanview/leanview/releases/latest>.

### How to check what you download

APKs are signed with a certificate of their own (`CN=Leanview`). Its SHA-256 fingerprint is in the [README](README.md#check-that-the-download-is-genuine). Install LeanView only from that releases page.
