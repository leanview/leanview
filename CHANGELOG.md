# Changelog

Versions follow `major.minor.patch`. Each release is published at <https://github.com/leanview/leanview/releases>.

## 1.0.0

First public release.

- YouTube player for Android TV, Google TV and Android phones; no ads in the player and no account required. Optional Google sign-in for subscriptions and history.
- Same app for the TV (remote control) and the phone (touch); Settings > User interface > Screen type forces TV or Phone.
- Optional connection to your own compatible server and Invidious instance (Settings > Accounts); nothing is built in.
- Updates: when a new version exists in this repository's releases it is downloaded in the background, then you are asked to install it.
- Free software under the GPL-3.0; the source of each release is in this repository, tagged with the version. Settings > About > Licenses shows the license, the notice and the third-party notices.
- Backups go to the `LeanviewBackup` folder (Documents and Google Drive); backups made by the SmartTube app (`SmartTubeBackup`) can be restored.
- Languages: Spanish and English, plus the translations inherited from SmartTube.
- Based on SmartTube (MIT) and containing GPL-3.0 code derived from NewPipe and bgutil-ytdlp-pot-provider. Not affiliated with YouTube, Google or SmartTube.

## 1.0.0 (Español)

Primera versión pública.

- Reproductor de YouTube para Android TV, Google TV y teléfonos Android; sin anuncios en el reproductor y sin necesidad de cuenta. Inicio de sesión con Google opcional para suscripciones e historial.
- La misma aplicación sirve para el televisor (mando) y el teléfono (táctil); Ajustes > Interfaz de usuario > Tipo de pantalla fuerza TV o Teléfono.
- Conexión opcional a tu propio servidor compatible y a tu instancia de Invidious (Ajustes > Cuentas); no viene ninguna incorporada.
- Actualizaciones: cuando hay una versión nueva en las versiones de este repositorio se descarga en segundo plano y después se te pide instalarla.
- Software libre bajo la GPL-3.0; el código fuente de cada versión está en este repositorio, con la etiqueta de la versión. Ajustes > Acerca de > Licencias muestra la licencia, el aviso y los avisos de terceros.
- Las copias de seguridad van a la carpeta `LeanviewBackup` (Documentos y Google Drive); se pueden restaurar las hechas por la aplicación SmartTube (`SmartTubeBackup`).
- Idiomas: español e inglés, más las traducciones heredadas de SmartTube.
- Basado en SmartTube (MIT) y con código GPL-3.0 derivado de NewPipe y de bgutil-ytdlp-pot-provider. Sin afiliación con YouTube, Google ni SmartTube.
